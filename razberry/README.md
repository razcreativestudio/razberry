### `RAZBerry Browser`

RAZBerry is a modern, privacy-focused and ultra-productive Firefox-based web browser customized and maintained by RAZ Creative Studio!

---

### Key Features

- **Raspberry Theme Identity**: Distinctive signature `#C72C48` primary color and tailored dark/light aesthetic.
- **Vertical Tabs & Spaces**: Unclutter your browsing experience with powerful tab organization.
- **Side-by-Side Split View**: Multi-task effortlessly without opening secondary windows.
- **Zero Invasiveness**: Built on a solid, open-source Firefox foundation.

---

### Quick Commands

```bash
# Install dependencies
npm install

# Import configuration
npm run import

# Build UI fast
npm run build:ui

# Launch browser
npm start
```
